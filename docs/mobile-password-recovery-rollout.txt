CineGeek in-app password recovery — 23 November 2026

User intent and current account
The owner wants the reset email to open CineGeek and complete the password change
inside the iPhone app. They confirmed a fresh reset in Private Safari and subsequent
app sign-in both work. The normal browser 404 is isolated to stale browser state.
PR #34's earlier website-only publishing question was NOT approved; its scope is
now this native recovery change. No deployment or email-template change has run.

Implementation
- Official @capacitor/app 8.1.2 handles cold-launch and warm app links through the
  existing SceneDelegateProxy. Do not replace the current native purchase/Focus code.
- The exact HTTPS origin is https://cinegeek.lovable.app and the only linked route
  is /reset-password. AASA binds it only to RAG9TBP6L8.app.cinegeek.mobile, verified
  against the existing signed archive. The new Associated Domains entitlement
  requires signing-profile refresh before distribution.
- The prepared email template links directly to that HTTPS route with TokenHash
  in the fragment. The fragment is not sent in HTTP requests or referrer headers.
  No custom URL scheme accepts recovery credentials.
- A Continue tap redeems the one-time hash with Supabase verifyOtp(type=recovery).
  Merely previewing the browser fallback does not consume it. Only a verified
  response can unlock password fields, and getUser checks the same account before
  updating the password. Ordinary sessions and malformed links cannot unlock them.
- Recovery replaces any existing app screen before normal account/onboarding
  redirects. Newer links, cancellation and sign-out invalidate older pending work.
  A later retry of the same link is allowed to reach server validation.
- Completion ends the temporary recovery session and offers in-app sign-in.
  Existing implicit browser reset links remain supported during rollout.
- The earlier cache correction stays as protection for desktop/uninstalled-app
  fallback only. No automatic update/reload is registered during recovery.
- Capacitor bridge payload logging is disabled to keep recovery hashes out of
  device logs. No owner password or reset credential is included in these files.
