CineGeek — ten-question allowance and subscription-period spending
26 November 2026

Approved scope
Monthly and Annual Pro: 10 successful questions per subscription month; no rollover.
Free: no included questions. Question-pack purchases remain disabled.
Account model-cost ceiling: $4 per subscription month, including failed attempts.
Annual refreshes monthly, using the same original anniversary as the question allowance.
The whole-question $0.35 cap, 64-call guard, optional daily cap, $5 lifetime beta
pool, private CLI test cap, model, prompts, context and spoiler checks are unchanged.
Production sales remain disabled. This does not fund or activate public sales.

Accounting
Ten questions at the $0.35 ceiling leave $0.50 inside the $4 ceiling for failed
work. This is not a separate failed-work fund or a guarantee that every possible
request completes: excessive failed work, unknown charges or the global stop
can still prevent another answer. No question is deducted for such a failure.
Pending/unknown calls retain their full reservations; actual settlement still
updates the same ledger. There is no reset, refund, provider change or downgrade.
The first migrated period also retains old calendar-month costs. Subsequent
periods use the subscription anniversary (including month-end clamping).
Private test grants keep their previously approved base plus extra allowance:
the existing $3+$2 grant remains $5, not $6, and its expiry is unchanged.

Validation
The updated SQL and UI tests cover Free, both Pro plans, ten-question exhaustion,
already-used balances, subscription anniversaries, plan switches, refunds,
mid-day resets, concurrent reservations, failures, unknown charges and permissions.
Real PostgreSQL concurrency tests use a network-isolated disposable container.
No provider or Apple API calls are needed for the accounting tests.
