Scene explanations with earlier-episode background — 26 November 2026

Behaviour
TV scene questions now use the same earlier-episode preparation path as ordinary
character/story questions. Explicit requests for only the current episode/scene
still exclude previous episodes. Recap routing is unchanged.

For example, at episode 2, 05:00, "Explain this scene" can use the current
exchange and an earlier episode's promise to explain the present decision.
The source selector receives the actual target exchange while choosing relevant
background, including when the historical sources span multiple batches or
require search expansion. Current scene sources remain in the selected packet.
Global narrowing also retains their adjacent qualifying exchanges. The existing
20,000-character and 55-source final limits still apply; overflow fails closed.

The answer still needs current-scene evidence. A verified earlier-episode
paragraph alone cannot be published as an explanation of what is happening now.
Historical dialogue remains marked as historical; the existing independent
reviewer must establish its connection without treating it as a current action.
Missing current evidence and missing earlier coverage remain explicit limitations.

Unchanged
Source title/episode/edition checks, timestamp and reveal boundaries, writer and
independent factual/spoiler reviewer prompts, model/provider, reasoning/output
settings and attempt bounds are unchanged. No prior AI prose becomes evidence.
Production limits remain $5 global, $0.35/question and $3/account/calendar month;
private test cap stays $11. No purchase setting, SQL, key or live configuration
is changed. Real purchases remain disabled.

Work/check revision is watch-work-2026-11-26-scene-context-v1 /
watch-checks-2026-11-26-scene-context-v1, so old intermediate selection results
cannot be resumed through the changed selection logic.
