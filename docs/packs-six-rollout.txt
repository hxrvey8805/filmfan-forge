Behaviour

- Pack prices remain 150 XP. AI, subscription permissions, daily reward odds and real-purchase flags are unchanged.
- Sealed CineGeek pack -> explicit Reveal card -> portrait, Keep/Skip. Full shelf presents six replacement choices. Close preserves an undecided card. Reduced-motion respects system preference.

Approved editorial category odds: Established 60%, Star 30%, Icon 10%.
Actor catalogue: 16 established, 16 stars, 12 icons (44 people).
Director catalogue: 12 established, 12 stars, 12 icons (36 people).
Within each category every person is equally likely. Each icon has 10% / 12 = approximately 0.8333% per pack (1 in 120), not 10% individually. Independent draws, duplicates possible; no guaranteed icon after ten packs.
The previous implementation sampled TMDB popularity pages; directors could be overrepresented across popular films. It did not provide stable rarity odds. The new frozen named catalogue replaces that source of probability.

Draw integrity
- Crypto uint32 randomness with rejection sampling: category roll then uniform name.
- A service-only RPC saves the versioned name/category before TMDB access. Network errors, lease expiry, concurrent requests and reopen cannot select another person.
- Each frozen name maps to a reviewed TMDB identity. Details must match the ID and normalized name or documented alias, then actual combined acting/directing credits must verify the role. Same-name search collisions cannot stall a valid pack. Failed identity/credit checks never reroll. Missing images use initials.
- Client cannot mint or modify draws/cards/XP. Wallet locks serialize decisions; table trigger also enforces six.
